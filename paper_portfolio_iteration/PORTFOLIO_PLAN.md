# Portfolio iteration order

## Stage 0 — completed setup target

Freeze public baselines, preserve remote project snapshots, inventory evidence,
and write one falsifiable next-experiment protocol per paper. Manuscripts remain
unchanged during this stage.

## Stage 1 — parallel high-information work

1. **A11 correlated majority vote:** run the smallest preregistered ordered-rollout
   study that jointly measures full-vote agreement, gold correctness, generated
   tokens, wall-clock latency, and realized cancellation savings.
2. **A2 erase late / absorb early:** define the observable enable rule before
   looking at test outcomes, then test it on both a naturally harmful/noisy case
   and a benign-but-hard case with matched paths and multiple seeds.
3. **A2 subgroup mix ranking:** first resolve the Proposition 5 scope in proof and
   prose. Only then test the surviving paired certificate on a real temporal or
   geographic subgroup-mixture shift, including abstention cost.

## Stage 2 — evidence-grounded manuscript revision

Revise only claims supported by Stage 1 evidence; update the claim-evidence map,
decision log, build record, and score trajectory in the same change.

## Stage 3 — isolated blind re-review

Use fresh reviewers with no access to prior scores. Promote a checkpoint only if
the audit is clean and its median score improves; otherwise retain the recorded
best checkpoint.

The internal discrete scoring rubric remains the repository's ICLR 2026 proxy.
Official ICLR 2027 author/reviewer requirements and style hashes were separately
verified on 2026-08-22; see `ICLR2027_REQUIREMENTS.md`.
