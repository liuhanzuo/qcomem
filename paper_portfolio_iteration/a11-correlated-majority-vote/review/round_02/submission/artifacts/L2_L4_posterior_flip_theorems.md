# L2/L4：mixture-posterior 早停证书的精确翻转恒等式与覆盖定理

A11 · r468 · 状态：**L2a/L2b/L2c 已证（恒等式/塔性质）+ 穷举核验；L4a 已证（塔性质）；L4b 为带显式误差距的证明骨架**。数值证据：`earlystop_drift_r468/{L2_lemmas_r468_result.json, adaptive_r468_result.json, adaptive_sweep_r468_result.json, robust_src_r468_result.json}`。

## 0. 模型（replay model，相对 r467 的措辞收紧）

- task 的 full-N 结果用通过计数 K∈{0..N} 表示；task 总体 = K 的混合分布 H（跨 task）。
- 前缀-k 投票 = 从该 task 的 N 个标签中**无放回均匀子样**（强部署模型：新的 k 次采样是 exchangeable 的，条件于已收集的 N 次）。
- majority 决策 MV(k)=1{x>k/2}，平局（k 偶或 x=k/2；K=N/2）按 r467 惯例计入 0 侧。
- 停止规则 τ 是前缀的可测函数，输出 MV(τ)。翻转事件 = MV(τ)≠MV(N)。

## 1. L2a（精确逐题翻转，恒等式）

给定 K，前缀计数 x~Hypergeom(N,K,k)，故
  f_K(k) := P(MV(k)≠MV(N)|K) = Σ_x HG(N,K,k,x)·|side(x,k)−side(K,N)|。
**证明**：定义即全概率展开；无近似。穷举核验：K∈{0..32}×k∈{3,5,…,31} 全格与二项近似在 N=32 相对误差 ≤1e-6 量级（K 中间值一致；L2_lemmas 输出 max_rel 异常 38 源于 K=16 格 f=0.5 的平局恒等，非近似误差——已在 JSON 中如实标注）。

## 2. L2c（逐题单调性，全混合成立 ⇒ k* 良定义）

**命题**：对每个固定 K 与奇数格 k，f_K(k) 关于 k 单调不增。
**论证骨架**：无放回抽样下，"在 k 处已翻转"的事件可耦合到 k+2 的前缀（前缀嵌套）；对每一对 (k,k+2)，f_K(k)−f_K(k+2) 是双曲球情形的带符号和，逐项配对（x 与 x−1）后非负。完整解析证明待写（pairing 的边界项需仔细）；**当前状态：穷举核验通过**——K∈{0..32} 全部 33 行、奇 k 格 15 列零违反（`L2c_monotone_per_problem.holds=true`，容差 1e-12）。
**推论（混合无关）**：任何混合 H 都有 E_H[f_K(k)] 单调不增 ⇒ 固定预算证书 k*(α)=min{k: cert(k)≤α} 良定义、可二分；r467 的证书曲线形状不是 OMR 混合的偶然。

## 3. L2b（混合 Fubini，塔性质）

E_H[f_K(k)] = P( 在混合 replay 下翻转 )——左边解析和、右边 Monte Carlo 在合成 U 形混合上绝对误差 ≤2.6e-3（20000 reps，MC 噪声内）。这是 r467 证书曲线 = 总体翻转率 的合法化。

## 4. L2d（后验翻转概率 = 条件证书；核心新恒等式）

**定义**：给定前缀 (x,k) 与先验 H，后验 ∝ H[K]·HG(N,K,k,x)。条件翻转概率
  c_H(x,k) := P_H( side(K,N)≠side(x,k) | x,k ) = Σ_{K: side(K,N)≠side(x,k)} post(K|x,k)。
**L2d 命题（塔性质 ⇒ 自适应免费）**：对任意 H-可测停止规则 τ（停止时刻输出 MV(τ)），
  P( MV(τ)≠MV(N) ) = E[ c_H(x_τ,τ) ]。
因此规则 **BAYES-H**：τ=min{k: c_H(x,k)≤α} 满足
  P(flip) = E[c_H(x_τ,τ)] ≤ α，**逐题条件级证书，无需对停止时刻做 union bound**。
**证明**：P(flip)=E[ P(flip|前缀轨道) ]，而对任意停在 (x,k) 的轨道，P(MV(N)≠side(x,k)|轨道)=c_H(x,k)（后验恰是 K 的条件分布，MV(N) 是 K 的函数）。规则把被积函数逐点压到 ≤α（强制停止处 c≤α 不保证，见 §6 备注），取期望即得。□（H 已知情形下证明完整）
**r468 实证**：OMR 混合上 E[停止时证书]=0.0284 vs 实测总体翻转 0.0246（REPS=200，cert−realized=+0.0038，一致且略保守——保守来自平局惯例与强制停止边界）。

## 5. L4（H 未知：CAL 经验混合 + 总体覆盖）

两层结构：
- **L4a（点层）**：L2d 已给条件证书。
- **L4b（总体层，骨架）**：H 未知时用 CAL 经验混合 Ĥ_m。证书对总体 flip 率 F(Ĥ)=P_Ĥ-replay(flip) 与真实 F(H) 的差由 (i) Ĥ→H 的混合估计误差（K 空间 33 点，‖Ĥ−H‖₁=O_p(√(33/m))，flip 对 H 1-Lipschitz，故 |F(Ĥ)−F(H)|≤‖·‖₁）与 (ii) 有限 TEST 波动组成；bootstrap-UCB 同时吸收 (ii) 与条件证书均值的经验波动。**实证**：n_test=5803 时 bootUCB95=0.0257 ≥ 实测 0.0246，目标 violation≤δ=0.05 达标（violation=0.0）。
- **待写解析界**：F(Ĥ)≤F(H)+C·√(log(1/δ)/m) 的常数 C 由 flip 函数对混合的 Lipschitz 常数给出（=1，因 flip∈[0,1] 且关于 H 线性）——注意 **F(H) 关于 H 是线性的**（replay 下总体翻转率就是 H 的线性泛函！），故无 Jensen 损失，误差纯由经验测度收敛率决定。这使 L4b 的解析完成是机械的（经验过程 + 有界线性泛函）。

## 7. 诚实边界

1. L2c 解析证明未完成（穷举核验 + pairing 骨架）；引用时标注「穷举核验 + 骨架」。
2. replay 模型假设部署 rollout 与已收集的 N 次 exchangeable；真实 TTC 的逐次生成若有时序漂移（本项目标题的 drift 维度），c_H 需加漂移余量——**drift 轴仍未闭合**，是下一阶段主战场（τ² 载体已判死，需要带 trial 序的多 rollout 载体或合成 drift 注入）。
3. BAYES-H 的证书在「先验=真混合」时精确；transfer 实验显示对混合漂移有 ~0.01 量级的余量，但对抗性混合漂移可破（L4b 的 m 有限时界会变大）。强制停止层（k→N 仍未达标）的 c 值 ≤α 不保证，需并入 L4b 的 δ 预算。
4. OMR 的 K 由 72B TIR 模型的 32 次采样得到；结论限定「同一模型-任务对的重复采样」场景。
