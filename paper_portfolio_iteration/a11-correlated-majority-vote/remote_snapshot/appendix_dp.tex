\section{Exact dynamic program for the adaptive rule}
\label{app:dp}

We compute, for a fixed true count $K$ and frozen prior
$\widehat H=\widehat H_m$, the exact per-task flip probability
$g(K;\alpha,\widehat H)$ and expected stopping time $\E[\tau\mid K]$ of
BAYES-H under the replay model, by dynamic programming over prefix states.

\paragraph{State space and transitions.}
A state is a prefix $(k,x)$ with $0\le x\le k\le N$, $k\ge 0$. Under
count $K$, the next draw is a uniform element of the remainder, so the
transition kernel is
\[
\P(x_{k+1}=x+1\mid k,x,K)=\frac{K-x}{N-k},
\qquad
\P(x_{k+1}=x\mid k,x,K)=\frac{N-K-(k-x)}{N-k},
\]
and the initial state has $\P(x_0=0)=1$. The state graph is a DAG
($O(N^2)$ states, $O(N^2)$ edges), so a single backward pass is linear
in the number of states.

\paragraph{Certificate table.}
The posterior $\P(K=j\mid k,x)\propto \widehat H[j]\,\HG(N,j,k,x)$ and
$\cert(x,k)$ are precomputed once for all $(k,x)$ on the $O(N^2)$ grid
(the forced-stop value at $k=N$ is the indicator
$\mathbf 1\{\mathrm{side}(x,N)\neq\mathrm{side}(K,N)\}$, deterministic in
$K$). A state is a \emph{stop state} iff $k\ge 3$ and
$\cert(x,k)\le\alpha$; $k=N$ is a stop state by truncation.

\paragraph{Recursions.}
For a fixed $K$, define $V(k,x)=\P(\MV(\tau)\neq\MV(N)\mid k,x,K)$
and $T(k,x)=\E[\tau-k\mid k,x,K]$. Then
\[
V(k,x)=
\begin{cases}
\mathbf 1\{\mathrm{side}(x,k)\neq\mathrm{side}(K,N)\}, & (k,x)\ \text{stop state},\\[4pt]
\dfrac{K-x}{N-k}\,V(k+1,x+1)+\dfrac{N-K-k+x}{N-k}\,V(k+1,x), & \text{otherwise},
\end{cases}
\]
and the same recursion with
$T(\cdot)=0$ at stop states and $T(k,x)=1+\text{(continuation mean)}$
otherwise. The requested quantities are $g(K)=V(0,0)$ and
$\E[\tau\mid K]=T(0,0)$. The per-task exact saving is
$1-\E[\tau\mid K]/N$; population quantities follow by linearity,
$\sum_K H[K]g(K)$, for any mixture $H$. The same forward pass yields the
exact forced-stop occupancy $\P(\tau=N\mid K)$: on the TEST split it is
$0.59\%$ at $\alpha=0.05$ and $1.10\%$ at $\alpha=0.02$.

\paragraph{Complexity.}
For each $K$: $O(N^2)$ states, $O(1)$ work per state after the
certificate table is frozen, so all 33 values of $K$ cost
$O(N^3)\approx 3.6\times 10^4$ flops at $N=32$ --- negligible. This is
why every TEST number in the main table is an \emph{exact replay
quantity}, not a Monte Carlo estimate.

\paragraph{Cross-check against simulation.}
The DP is validated against an independent replay Monte Carlo
implementation (fresh random prefixes) on the same frozen prior: the
maximum absolute deviation over the checked cells is $0.043$, within the
pre-set tolerance $3\sigma_{\rm MC}=0.075$ (the check includes cells at
$\alpha=0.01$, whose realized flips are small and inflate the pooled MC
standard error); PASS. See \texttt{fit\_cal\_test\_r469.py} and the
self-check block of \texttt{fit\_cal\_test\_r469\_result.json}.
