014                                               A BSTRACT
015
016            Long-context systems commonly retain or reconstruct key–value state at every
017            layer. We study a training-free alternative on a frozen backbone: cache one acti-
018            vation tensor per chunk at depth j, retrieve a fixed number of chunks, and recom-
019            pute only the upper layers. CoMem implements this write–retrieve–read pipeline.
020            With fixed top-k, model read length is independent of document length and the
021
               measured GPU read-time working set remains approximately flat through 128k
               tokens. The external activation store, raw text, and BM25 index still grow with
022
               the document, so this is not a constant-memory system.
023
               Matched measurements on Qwen3-8B separate the retrieval operating point from
024
               the depth-cache trade-off. A fixed-k short read provides the working-set benefit.
025
               At the same 6.7k-token read in a 128k memory check, moving from j=0 to j=12
026            saves about 0.3 GB, a read-length-scoped quantity rather than a general memory
027            benefit. The matched j=12 read is less accurate than re-forwarding the same
028            retrieved chunks from j=0. In a five-arm decomposition, the contrast remains
029            significant when selection, decoding, chunk-independent encoding, and position
030            relocation are held fixed; a residual lower-band context-set difference prevents
031            interpreting it as a fully deconfounded causal effect. The relocation contrast is
032            null at the scored endpoint but not at the raw-generation level.
033            The preregistered depth sweep has the same direction: pointwise and without mul-
034            tiplicity correction, every tested j≥2 read loses to matched j=0 on the same sam-
035
               ples, and no deeper point recovers it. The load-bearing j=12 comparison remains
               significant under Bonferroni correction, although the curve is not strictly mono-
036
               tone. Because the headline 4k magnitude was selected and depends on the regis-
037
               tered reader convention, the reusable conclusion is the direction, not a convention-
038            independent effect size. The result bounds what this frozen, training-free back-
039            bone gives up; it does not bound recovery after training for cache compressibility
040            or establish superiority over unimplemented prior systems.

043   1   I NTRODUCTION
044
045   Long-context inference has two different scaling problems: the model’s active working set grows
046
      with the sequence it rereads, and persistent state grows as more text is retained. KV eviction bounds
      the former by discarding tokens (Xiao et al., 2024b; Zhang et al., 2023; Li et al., 2024) and re-
047
      trieval bounds it by selecting a short pack, but both usually retain raw tokens or full-layer KV. We
048
      ask whether the depth axis provides another operating point: can a system retain one intermediate
049   activation tensor per chunk and reconstruct only the layers above it when that chunk is retrieved?
050
051   CoMem answers this question with a deliberately simple, training-free pipeline on a frozen back-
052
      bone (Figure 1). A write pass chunks a document, runs each chunk through layers [0, j) with chunk-
      local positions, and stores the c × d residual activation hj together with a raw-text BM25 index.

073   an exact transformation of the deployed input: the persistent hidden/text store is O(context), and
074   relocating chunk-local j > 0 states changes the computation. The narrow benefit is that, for fixed

077   The central experimental question is consequently not whether retrieval helps, but what the depth
078   cache contributes given the same retrieval. We isolate it by comparing j = 12 with j = 0 while
079   holding the selected chunks, query, scorer, and decoder fixed; the j = 0 arm re-forwards the same
080   retrieved raw tokens through all layers and is the matched reference. That comparison exposes a
081   directional read-out cost rather than a free compression: at the preregistered BABILong qa1 deci-
082
      sion cell the matched j=12 read is worse than j=0 under both the frozen reader and a sensitivity
      reader that removes model-generated option enumerations, with the magnitude reported as an in-
083
      terval rather than a point value (Table 2). We therefore treat depth caching as a quality–systems
084
      trade-off, not evidence that a mid-layer state is a sufficient statistic for general “understanding.”
085   A five-arm decomposition then freezes chunk-independent encoding and position relocation sepa-
086   rately and together: the depth-varying arm remains worse than j = 0, whereas relocation is null
087   at the scored endpoint. This isolates depth with respect to those named factors, while a residual
088   lower-band context-set difference prevents a fully deconfounded causal interpretation (Section 5.2).
089
090   Closest work and the gap we fill. The closest prior designs are Layer-Condensed KV (Wu &
091   Tu, 2024), which also caches a single shallow state on the layer axis but lacks top-k retrieval, and
092   HCache (Gao et al., 2025) and KV-Direct (Qasim et al., 2026), which restore or replace state from
093   intermediate activations without document retrieval (Section 2, Appendix A). What this comparison
094   set does not provide is a matched, preregistered measurement that holds retrieval, selector, scorer,
095
      and decoder fixed while changing cache depth and reports the resulting quality cost. We provide
      that measurement: an overall downward trend with a consistent directional loss at the registered
096
      comparisons. CoMem is the vehicle on which the protocol runs rather than the contribution by
097
      itself. Our empirical positioning is internal—full context, matched j=0, cached j=12, and the
098   author re-forward controls; a same-bed comparison to a prior system is not run and remains future
099   work.

114   2   R ELATED W ORK AND C ONTRIBUTION B OUNDARY
115
116   Token-axis methods choose which token states to retain (Xiao et al., 2024b; Zhang et al., 2023;
117   Li et al., 2024; Cai et al., 2024; Lin et al., 2026), and retrieval-and-reuse serving systems keep
118   full-layer KV for retrieved chunks (Yao et al., 2024; Jin et al., 2024; Gim et al., 2024); both leave
119
      the layer axis untouched. The three nearest neighbours act on that axis: Layer-Condensed KV
      shares one condensed KV computed at a shallow depth across the upper layers (Wu & Tu, 2024),
120
      HCache restores evicted state from intermediate activations without document retrieval (Gao et al.,
121
      2025), and KV-Direct replaces full-layer KV with a residual-stream read once all retained tokens
122   are reconstructed (Qasim et al., 2026). Each of them either lets the read grow with retained tokens
123   or omits top-k selection, and—decisively for this paper—none measures cache-depth fidelity under
124   a fixed retrieval, so the quality price of reading a cached mid-depth state has never been isolated
125   from the retrieval that makes the read short. CoMem’s boundary is accordingly the combination
126   of a one-depth per-token store, external BM25 top-k selection, and full upper-band recomputation:
127   we claim neither the individual ingredients, nor numerical exactness for relocated j > 0 states,
128   nor superiority over designs we do not implement, and the author’s full-depth re-forward control is
129   labeled as ours rather than as an implementation of any published method. Appendix A gives the
130
      per-family comparison, the mechanism-boundary table (Table 4), the position-remap and external-
      memory neighbours (Xiao et al., 2024a; Sun et al., 2024; Mohtashami & Jaggi, 2023; Tworkowski
131
      et al., 2023; Borgeaud et al., 2022; Wu et al., 2022; Bertsch et al., 2023), and the independence
132
      statement for the 2026 preprints (Qasim et al., 2026; Gelberg et al., 2026; Lin et al., 2026).

      What is and is not exact. On one contiguous sequence with unchanged positions,
163   F[j,L) (F[0,j) (x)) = F (x) up to implementation precision; this is an algebraic split/rejoin check.
164   The deployed j > 0 path is different: chunks are encoded independently, selected, relocated, and
165   jointly read with a query. There is no exactness guarantee for that transformation, so we measure its
166   fidelity against the same-retrieval j = 0 arm, where selected raw tokens are re-forwarded through
167   the whole model; at j = L no model layers remain to condition the stored representation on the
168   query, so intermediate j is a quality–compute knob. Two factors are confounded at every j > 0:
169   (i) chunk-independent encoding (each chunk is written with chunk-local positions, without cross-
170   chunk attention during the write), and (ii) position relocation (retrieved chunks are reassigned fresh
171
      contiguous positions at read). An identical-position split/rejoin is lossless by design and so isolates
      neither factor; disentangling (i) from (ii) requires the registered dual-step ablation of Section 5.2,
172
      reported separately from the headline depth curve.

177   Everything in this paper is measured on a frozen, training-free stack: the 36-layer Qwen3-8B back-

181

182
      from headline claims: our result is a single fixed-configuration test, not a claim that k = 12 is opti-
183   mal. How the depth cost changes with k is unknown, and a matched k-sweep at the 4k decision cell
184   remains future work.

      5.3   S ERVING ESTIMAND : WHAT THE FIXED READ COSTS AND BUYS
379
380   Across the separate niah single serving sweep, fixed-read CoMem retains perfect accuracy,
381   whereas the full-context baseline’s longest point was run outside this Qwen3 checkpoint’s enabled
382   positional regime; that point is greyed and annotated in Appendix Figure 3 rather than treated as
383   a comparison, so its 128k cliff is a positional-regime artifact, not evidence of systems-level full-
384   attention collapse. At the longest context CoMem uses 3.9× less GPU memory and its registered
385   per-query read remains approximately length-invariant, while full attention stays feasible below the
386
      card’s 97.8 GB capacity rather than failing out of memory. This memory contrast is read/prefill-only
      — decode rebuilds the upper pack at each token, so it is not an end-to-end win, and a matched j=0
387
      short read (Section 5.2) delivers the same operating point. The recorded read/prefill endpoints are
388
      tabulated in Appendix Table 7 rather than plotted, because three endpoints are not a sweep; that
389   table also prevents this comparison from being misread as a depth-cache ablation, since full context
390   versus CoMem changes both selection and representation. Retrieval keeps the read in-window; it is
391   a whole-system retrieval comparison, not a depth saving.
392
      The matched E1 check instead holds the selected 6.7k-token read fixed: its median-of-three peaks
393
      are 18.2 GB at j = 0 and 17.9 GB at j = 12, reproduced in two trials (six of six measurements). The
394
      resulting 0.3 GB saving has 0.1 GB print granularity (range 0.2–0.4 GB) and matches the analytic
395   read-time band (j/L)BKV read len with j/L = 12/36. We call this a read-length-scoped analytic
396   null: weights and the 128k write transient dominate the 18.2 GB peak, so it is not general evidence
397   that depth caching is memory-free. E1 is a memory endpoint and the direction estimand’s primary
398   endpoint is qa1 accuracy, so neither predicts the other.
399
      For one generation stream, that table’s registered write/read times imply a balanced break-even of
400
      approximately 26 repeated reads per written document (Q⋆ = W/(tj0 −tj12 ) = 6.65/0.26 = 25.58
401   on the rounded serving endpoints). The quotient is sensitive to that rounding: the 0.26 s numerator
402   is a difference of two median-of-three endpoints at 0.01 s print granularity, so a ±0.01 s perturbation
403   moves Q⋆ across roughly 25–27 reads/document, and we quote it as “about 26” rather than a two-
404   decimal constant. Decode is excluded and the implementation recomputes the upper band at each
405   generated token, so Q⋆ is read/prefill-only, has no established end-to-end analogue, and would shift
406   under an accounting convention including decode. We claim no end-to-end time saving from depth;
407   the serving-time calculation and the E1 memory check remain different protocols, and neither turns
408   the selected 4k quality loss into a universal Pareto frontier.

415
416   The system is not constant-memory. The fixed-k pack is bounded, but GPU peak is not constant:
417   it stays nearly flat through 128k and rises materially at the separate one-million-token serving point
418   (Appendix H). The activation/text/index stores grow as O(context); index size and BM25 latency
419
      remain unmeasured.
420
421
      Depth caching loses information needed by the deployed read. The same-retrieval j = 12
      arm is worse than j = 0 on qa1 and the registered RULER/LongEval aggregates, and no tested
422
      deeper point recovers j=0 accuracy (Appendix Table 5); identical-position split/rejoin does not
423
      validate relocated chunks. The answer-anchored 512-cap result is underpowered and the directional
424   diagnostics are post-hoc, leaving a clean magnitude open. The quality cost is also task-dependent:
425   the fixed read retains near-perfect recall on needle-style single-supporting-fact probes, so that claim
426   does not extend to multi-hop composition, which is not evaluable under the registered adjudicator
427   (Appendix G). The 16k dense/re-forward controls are a non-rejection, not an equivalence test, so a
428   retrieval-side deficit of a few pp is not excluded, though it remains far below the depth effect.
429
430   The result is training-free and therefore bounded. Every number here comes from a frozen
431   backbone with no parameter update, so the measured depth cost is what a training-free deployment
      pays. It is not a statement about what is achievable in principle: representations can be trained to be

457
      CoMem provides a factorized measurement of retrieval and cached depth. On the tested Qwen3-8B
458   configurations, fixed top-k retrieval keeps the model read short as document length grows, while the
459   external activation/text store grows linearly. At the measured 6.7k-token read, moving from j=0 to

600   token of a selected chunk at only one depth, so its storage reduction is on the layer axis and does not

602   layer axis, sharing one condensed KV computed at a shallow depth across the upper layers (Wu &

1438   The pinned rows of Tables 2 and 8 carry the primary magnitude. Their paired risk difference is
1439   (c − b)/n; the exact conditional interval applies Clopper–Pearson to c/(b + c) and rescales it as
1440   (2p − 1) s/n, where s = b + c and p = c/s (registered inputs are in Table 12). It conditions on
1441   the observed discordant pair count and remains the primary interval; Table 16 also reports the wider
1442
       Newcombe Method 11 cross-check, which corrects the square-and-add construction by the observed
       pairing correlation. Earlier versions of this appendix omitted the pairing-free construction on the
1443
       grounds that it discards the paired structure; we now report it deliberately as the assumption-free
1444
       floor, because the raw contexts of these historical cells cannot be re-audited by a reviewer. Setting
1445   the pairing correlation to zero in the same square-and-add formula gives an interval that uses only the
