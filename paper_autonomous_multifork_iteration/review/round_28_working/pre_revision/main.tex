\begin{abstract}
Forking many continuations from one long prefix raises two separate questions:
whether request state is isolated and which memory denominator is saved.  In a
hybrid model, token-indexed attention KV and recurrent state make those claims
easy to conflate.  We present \method, a receipt-bound audit contract, and apply
it to one frozen Qwen3.5-35B-A3B configuration.  We distinguish three evidence
levels: (i) receipt-complete lifecycle/storage predicates conditional on honest
producer capture and external byte bindings; (ii) selected independent operator
corroboration; and (iii) positive-control gate reachability.  Across eight
pre-specified books, 96 configurations cross full-copy/shared-document KV with
materialized/borrowed GDN bases at $N\in\{1,8,32\}$.  Registered token, canonical
full-logit, logical-KV, and final-GDN digests match across all four cells and 288
adjacent-fan-out comparisons; phase receipts show post-transition mutable GDN
state disjoint from bases and peers.  Separately, eight attention rows pass a
dense-FP32 oracle ($L_2\leq0.001743<0.005$), four preregistered GDN transitions
pass a NumPy recurrence, and nine live faults reach intended gates.  Per-call
compiled-binary/autotuning provenance remains unbound.  At $N=32$, shared KV
reduces median final allocated delta from $4.90$ to $2.23\gib$.  Unpooled Mac,
H20, HYPIC, and serving controls provide context, not audit evidence.  The result
is evidence about a captured receipt ledger for one sequential stack---not
independent producer recapture, end-to-end verification, or production capacity.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Best-of-$N$ decoding, agents, tree search, and document question answering
create many continuations from a common prefix.  Modern serving systems exploit
this structure through paged KV caches, prefix trees, and scheduling
policies~\citep{kwon2023pagedattention,zheng2024sglang,gim2024promptcache,srivatsa2025preble}.
For a Transformer, ``sharing the prefix'' can often be described as sharing
read-only KV blocks and giving each continuation private append blocks.  Hybrid
models complicate this picture: full-attention layers coexist with recurrent or
linear-attention layers whose compact state is updated in place unless the
runtime installs an explicit request-local view~\citep{yang2025gateddeltanet,lieber2025jamba,pan2025marconi}.

This creates two evaluation hazards.  First, matching output tokens does not
prove request isolation: two branches can agree while aliasing the same mutable
state, and a bug can affect both compared implementations.  Second, ``memory
saving'' may refer to logical payload, allocated cache pages, framework
allocator peaks, process-level device memory, or admitted service capacity.
Those quantities are not interchangeable.  An impressive cache-pool ratio may
be small after model weights and common runtime state enter the denominator.
An archival Mac control makes the first hazard concrete: two quantized CoMem
variants agree exactly with their shared BF16 split reference while the whole
split family disagrees substantially with vanilla dense (Table~\ref{tab:mac-motivation}).

We propose \method, a correctness-first receipt contract for a captured
ledger under trusted producer capture.  It partitions document and request state,
records page reservations and phase-aware recurrent-state rebinding,
fingerprints the Python attention callable, and combines a $2\times2$
ownership factorial with relational and independent numerical checks.  A
mutation specification and gate assignment fixed before candidate execution
then ask whether each advertised gate is sensitive to a corresponding live
fault.  The measurement side reports page
geometry separately from allocator deltas and phase-bounded peaks.  \method{}
is not a caching policy, kernel, or scheduler; its purpose is to make the
captured-receipt boundary of one frozen sequential implementation explicit and
machine-checkable; it does not independently attest to the producer, and its
per-call compiled dispatch remains open.

The primary contribution is the receipt-replayable audit contract; the frozen sequential case and
accounting reconstruction below are validation artifacts for that contract,
not separate mechanisms.  Concretely, we provide:
\begin{itemize}
  \item \textbf{Receipt-complete lifecycle/storage targets under trusted capture.}
  The contract maps immutable
  document KV, private append pages, borrowed versus materialized GDN bases,
  first-transition rebinding, tail COW, and callable provenance to typed
  records.  Lifecycle/storage predicates replay completely; compiled dispatch
  is partial (Sections~\ref{sec:contract}--\ref{sec:protocol}).
  \item \textbf{A relational factorial plus selected independent checks.}  Four
  KV-by-GDN ownership cells have identical registered token sequences and
  shape/dtype-bound CPU-FP32 logit, logical-KV, and GDN byte digests across
  eight pre-specified windows and three fan-outs.  This equality is relational
  and cannot exclude a common-mode defect; separately, selected full-attention rows
  pass an IEEE-FP32 dense oracle, and
  selected recurrent-core transitions pass a separate NumPy recurrence oracle,
  under tolerances fixed before execution (Section~\ref{sec:results}).
  \item \textbf{Positive-control reachability and explicit denominators.}  Nine
  live mutants reach their intended gates under matched-clean controls, without
  estimating detection rate or completeness, while
  allocator endpoints show which savings survive once model and runtime state
  enter the denominator.  A separate same-adapter cohort further exercises
  aligned-prefix cancellation, zero-scrub, exact reclamation, and stale-lease
  rejection without changing outputs or final state.
\end{itemize}

Relative to ordinary pass/fail tests, \method{} adds a joint replay
obligation: frozen roles, setup--first-transition--final lifecycle,
storage/call/accounting records, and a predeclared fault map must close
together.  The constituent checks are not individually new or exhaustive.

The supported claim is deliberately narrow: conditional receipt-level
ownership evidence for one frozen sequential stack.  The primary audit uses one model, one hardware
family, 16-bit KV, one 4,095-token partial-tail factorial and one aligned
4,096-token cancellation lifecycle, batch size one per request, and sequential
round-major model steps on one CUDA stream.  The
independent oracles cover selected attention and recurrent-core operators
conditional on captured internal inputs, not the full hybrid model.  A separate
single-request deployment cohort reports TTFT, TPOT, throughput, reusable-state
bytes, and F1 for vanilla dense, full-prefix cache reuse, and CoMem quantization;
it does not measure continuous batching, scheduler throughput, NVML capacity,
or maximum admitted concurrency.  The nearest executable hybrid-cache baseline
uses the authors' HYPIC code on the same checkpoint, slice, H20-3e hardware,
input cap, and decoding budget; its Full Recompute, Prefix Cache, and full
HYPIC arms use TP=1 and one streaming client.  The published Qwen3.5 panels use
TP=2, so this is a protocol-matched adaptation rather than a reproduction of
their published latency.  An independent receipt-instrumented cohort measures
retained-document tensor payload for Prefix Cache and HYPIC in that same fixed
configuration (eight workloads per arm).  A separate serving-framework panel
tests vLLM and SGLang cache-off/on controls; each experimental block is
interpreted on its own.

\section{Background and Related Work}
\label{sec:related}

\paragraph{Paged and prefix-aware inference.}
PagedAttention, Prompt Cache, RadixAttention, ChunkAttention, Hydragen, and
Preble establish block sharing, prefix reuse, shared-prefix computation, and
scheduling as prior art~\citep{kwon2023pagedattention,gim2024promptcache,
zheng2024sglang,ye2024chunkattention,juravsky2024hydragen,srivatsa2025preble}.
Our narrower question is what execution evidence demonstrates isolation when
several state types coexist.

\paragraph{Hybrid state and cache management.}
Gated Delta Networks maintain mutable compact state unlike token-indexed
KV~\citep{yang2025gateddeltanet}; Jamba is a hybrid architecture and Marconi
manages hybrid-model prefixes~\citep{lieber2025jamba,pan2025marconi}.  HYPIC
caches segment transition operators plus zero-start end states and recomputes a
small seam to enable position-independent reuse in hybrid stacks
\citep{liu2026hypic}.  Palu,
SqueezeAttention, and HeadKV instead study KV compression or budgeting
\citep{chang2025palu,wang2025squeezeattention,fu2025headkv}.  \method{} does
not replace these policies: it audits their ownership boundary.  Appendix
Table~\ref{tab:published-context} keeps their original-protocol numbers
separate from our common-model controls.

\paragraph{Persistent intermediate residual reuse.}
CoMem makes decoder split depth $j$ a reusable-context
axis~\citep{liu2026comem,liu2026understanding}.
Its \textsc{Write} stage persists a depth-$j$ residual per document token,
\textsc{Select} retrieves bounded chunks, and \textsc{Read} executes the query
and suffix layers.  This motivates our persistent document object.  A bounded
depth-7 deployment slice places Q8/Q4/mixed state beside vanilla dense and
full-prefix reuse, but \method{} claims neither a new selector nor a new
quality--latency frontier.

\paragraph{Evaluation and metamorphic testing.}
SCBench emphasizes cache lifecycles~\citep{li2025scbench}; metamorphic testing,
MT-DLComp, and CRADLE motivate preserved relations and independent checks
\citep{chen2018metamorphic,xiao2022metamorphic,pham2019cradle}; DNNMem motivates
separate memory denominators~\citep{gao2020dnnmem}.  We combine these established
ideas into a heterogeneous-state audit: adding resident branches must preserve
registered observables, selected captured-input operators receive independent
FP32 checks, and page-pool and allocator quantities remain distinct.  Appendix
Table~\ref{tab:closest} gives the component-by-component novelty boundary.

\section{The ForkAudit Contract}
\label{sec:contract}

Consider a document prefix $D$ and resident requests
$r\in\{1,\ldots,N\}$.  Let $\mathcal{A}$ be the full-attention layers and
$\mathcal{G}$ the recurrent linear-attention layers.  For
$\ell\in\mathcal{A}$, the state is a read-only set of document pages
$K^D_\ell$ plus a request-private reservation $K^r_\ell$.  For
$\ell\in\mathcal{G}$, it is a persistent prefix base $G^D_\ell$ plus the
request-local recurrent state $G^r_\ell$.  A logical fork is
\begin{equation}
  \mathcal{F}_r(D) =
  \bigl(\{K^D_\ell,K^r_\ell\}_{\ell\in\mathcal{A}},
        \{G^D_\ell,G^r_\ell\}_{\ell\in\mathcal{G}}\bigr).
\end{equation}

The checklist has seven audit targets.  A target may be fully witnessed,
partially witnessed, or left open; passing the case study must not silently
upgrade a partial witness into a proof.
\FloatBarrier
\begin{enumerate}
  \item \textbf{Frozen identity.}  Model, data, query bank, layer geometry,
  kernel descriptor, and protocol hashes are fixed before execution.
  \item \textbf{Prefix immutability.}  $K^D_\ell$ and $G^D_\ell$ have identical
  digests before and after all continuations.
  \item \textbf{Private ownership.}  KV reservations of distinct
  shared-document requests are disjoint in the common arena; independent
  materialized arenas have disjoint storage.  At setup, a GDN request either
  owns a materialized base or holds an explicitly read-only persistent-base
  alias.  After its first transition, all 60 mutable tensors must occupy ranges
  disjoint from the base and every peer.
  \item \textbf{Tail-safe append.}  If the last document page is partial, its
  valid tokens are copied once to a private page before a request appends.
  \item \textbf{Dispatch provenance.}  Both controls invoke the same recorded
  attention Python callable with the same query, mask, position, and append
  contracts; fallback and full-KV concatenation are forbidden.  This does not
  fingerprint a compiled Triton binary or autotuning choice.
  \item \textbf{Cross-arm equivalence.}  For the same query and schedule, the
  materialized and shared ownership arms must have exactly equal generated
  tokens, full-vocabulary logits, final logical KV, and request recurrent
  state.
  \item \textbf{Cross-$N$ prefix consistency.}  For each query observed at two or more
  fan-outs, its result at every larger fan-out must match its smallest-$N$
  result.
\end{enumerate}

\paragraph{Minimal adoption workflow and decision rule (normative).}
Applying \method{} to a sequential hybrid runtime requires four steps.
\emph{(1) Freeze and assign roles:} bind code, model, data, protocol, and the
mapping from runtime objects to document, base, request, and private-reservation
roles before candidate outputs.  \emph{(2) Capture mandatory records:} emit
setup, first-transition, and final lifecycle events together with canonical
content digests, normalized storage ranges, ordered append/dispatch receipts,
semantic outputs, and named allocator snapshots.  \emph{(3) Replay the seven
targets blindly:} an independent aggregate recomputes every applicable
predicate from frozen records; a target is receipt-complete (RC) only when all
mandatory records exist, \emph{partial} when evidence is sampled or proxy-level,
and \emph{open} when a mandatory record is absent or replay fails.
\emph{(4) Add fault records only for fault-sensitivity claims:} freeze the
target-to-gate map before outputs and retain clean false positives, wrong-gate
detections, and escapes as valid negatives.  RC remains conditional on honest
producer capture and external byte bindings; it is not independent producer
recapture or end-to-end or exhaustive correctness.  In the primary run,
terminal identity is RC but per-call compiled dispatch and autotuning provenance
remain partial.  We evaluate this workflow on the fixed Qwen runtime below.
Appendix~\ref{app:storage-schema}
gives the exhaustive target-to-record dependency matrix and the pointer-free
storage schema used by this audit.

Appendix Table~\ref{tab:normative-records} gives the four normative record
classes and their replay obligations.

Here and below, ``exact'' for a registered tensor-valued observable means
equality of a canonical serialization: contiguous CPU-FP32 bytes with shape
and dtype bound into the record, or the correspondingly specified logical-KV
or GDN byte digest.  It is not a claim that an unarchived device tensor was
compared bit-for-bit before canonicalization.

Targets 6 and 7 are relational self-consistency oracles.  They can reveal a
layout-specific error or an $N$-dependent change in recorded observables,
respectively.  The primary factorial additionally captures the same post-RoPE
query, logical K/V, position values, mask, and effective scale for one
rank-specific full-attention row selected by the pre-execution static plan and
compares the fused result with dense IEEE-FP32
attention.  A separate recurrent oracle captures four transitions originally
selected at layers 0, 10, 20, and 38 after the native BF16 q/k normalizer,
then evaluates the transition with a candidate-import-free NumPy FP32 token
recurrence.  A fresh single preregistration, frozen before the successful run,
binds this post-native-normalization boundary, the implicit query scale
$1/\sqrt{128}$, the four rows, tolerances, and seeded faults.  These are
independent numerical checks for selected
operator boundaries, not for upstream activation construction, q/k
normalization itself, every GDN layer, or the complete end-to-end model.

\section{Receipt-Bound Audit Protocol}
\label{sec:protocol}

\subsection{Frozen case-study geometry}

We instantiate and validate the contract in one fixed runtime configuration:
Qwen3.5-35B-A3B
\citep{qwen2026qwen35,qwen2026qwen35modelcard}: ten vLLM-0.26 Triton
full-attention layers with BF16 (artifact ``Q16'') KV, 128-token pages, and
thirty Transformers-torch GDN layers, run sequentially on eight H20-3e GPUs.
The ledger binds the Python attention callable but not the compiled binary;
each request's GDN digest covers 60 tensors.  Every ForkAudit correctness claim
is conditional on this stack.

Eight ranks use distinct PG-19 training books~\citep{rae2020compressive}, each
with one 4,095-token document and 32 non-overlapping queries.  The four-cell
factorial evaluates $N\in\{1,8,32\}$ and eight argmax steps; 39 query/generated
tokens enter KV, so the 127-token final document page exercises tail COW.
Appendix Table~\ref{tab:cohorts} separates this run from all context cohorts.

\subsection{Audit sequence}

Each cell hashes its frozen identity, builds document KV and persistent GDN
state, separately rebuilds allocator and witness cells, records setup--first
transition--final ownership, and executes one query plus seven continuation
steps.  It then compares registered tokens, logits, logical KV, and GDN state;
replays fixed-axis projections and one dense-FP32 sidecar per rank; and runs
matched-clean/live-fault pairs from fresh state.  Aggregation requires every
raw-byte binding.  Appendix Table~\ref{tab:witness} states target strength;
the request--base predicate is directly exercised at $N=1$.

\subsection{Controls, schedule, and oracles}

All requests are resident before sequential round-major steps on one CUDA
stream; this is not concurrent-kernel evidence.  Full logits are canonicalized
as shape/dtype-bound contiguous CPU-FP32 bytes, while logical KV, 60 GDN
tensors, immutable bases, call positions/masks/scales, storage, and allocator
records receive typed digests.  Replay closes these records, factor projections,
oracle math, and fault receipts, but cannot reconstruct unarchived device
tensors or independently recapture the producer.

The GDN oracle was preregistered before its successful execution with one
window, four layers, a post-native-q/k-normalization boundary, scale
$1/\sqrt{128}$, tolerances, and four wrong recurrences.  A prior discarded
diagnostic informed that boundary; it is chronology, not evidence from the
successful run.

\subsection{Memory denominators}
\label{sec:denominators}

For the primary ForkAudit experiment, we keep logical state, allocated pages,
synchronized PyTorch current/peak allocated/reserved bytes, and unmeasured
process/service capacity distinct; only pages and allocator bytes support its
quantitative memory claims, and phase-reset peaks are labeled by their
measurement window.  The deployment comparison uses a separate Store
estimand: the union of physical tensor byte ranges owned by the retained
document entry at its measurement boundary.  It excludes Python metadata,
preallocated pools, NVML deltas, and admission capacity.

\subsection{Governance and live mutation checks}

Pre-output ledgers bind code, model, data, queries, and protocol; the formal
primary rerun also verifies matching terminal source/model identity.  Nine live
mutations cover allocation/binding, tail COW, GDN aliasing, positions, masks,
callable identity, and paged-view type; each has a fresh matched control and
cleanup receipt.  These tests establish intended-gate sensitivity, not
completeness.

\section{Results}
\label{sec:results}

\subsection{Unpooled Mac motivation context exposes common-mode agreement}

Before the H20 audit, an archival Apple-M4-Pro control provides a compact
counterexample to treating implementation agreement as an independent oracle.
On the same six-document/six-query selected packs, vanilla dense MLX is the
external reference, while CoMem~\citep{liu2026comem,liu2026understanding}
reuses a depth-7 split residual in BF16, Q8, or Q4.  Across five fresh
processes, both quantized variants retain every answer-position top-1 decision
of the BF16 split path, yet that entire split family agrees with vanilla dense
on only 71.89\% of answer positions.  Table~\ref{tab:mac-motivation} therefore
motivates the later independent attention/GDN oracles; it is a small
teacher-forced mechanism control, not primary ForkAudit evidence, a second
ForkAudit deployment, or a cross-hardware performance comparison.

\subsection{Unpooled same-checkpoint deployment and nearest-work context}

Table~\ref{tab:h20-deployment} combines two separate conventional end-to-end

The rows expose tradeoffs, not a universal win.  Full-prefix reuse is fastest

workflow, frozen identity, prefix immutability, private ownership, tail-safe

Independent producer recapture and end-to-end correctness remain outside the

\subsection{Relational equality holds for every registered observable}

The primary factorial executes $8\times3\times4=96$ rank--fan-out--factor
configurations.  Each configuration is rebuilt once for allocator measurement
and once for ownership/semantic witnesses, for 192 live cells total.  The blind
aggregate reports exact token trajectories, full-vocabulary logits, final
logical KV, and final GDN values across all four cells.  Fixed-axis
projections also match: changing only GDN setup ownership leaves the KV
lifecycle/source/query/call schedule unchanged, while changing only KV
ownership leaves the GDN base values and transition trajectory unchanged.
The offline replay additionally reconstructs all 288 adjacent-fan-out
comparisons---$N=1\!\rightarrow\!8$ and $8\!\rightarrow\!32$ for every arm,
rank, and shared query identity---with no mismatch.
These are relational equalities among the registered cells: they support the
receipt-level ownership witness but cannot by themselves exclude a defect
shared by every arm.

The range witnesses explain where that equality comes from.  A borrowed GDN
cell begins with exactly 60 immutable persistent-base aliases per request; a
materialized cell begins request--base and request--request disjoint.  After a
request's first model transition, both policies bind 60 request-private mutable
tensors whose byte ranges are disjoint from the persistent base and all
completed peers.  Incomplete borrowed requests remain exact read-only aliases
until their own transition.  These predicates pass at setup, first transition,
and post-generation for every factor configuration.  In particular, the
$N=1$ cells directly exercise request--base disjointness rather than relying on
a vacuous peer comparison.

\section{Discussion and Limitations}
\label{sec:limitations}

\paragraph{What the experiment establishes.}
Conditional on honest capture and the registered byte bindings, receipts from
one frozen stack witness request/base and request/peer relations across ten
attention and thirty GDN layers.  Cross-cell equality, selected FP32 checks,
and positive controls are bounded levels, not closure of every common-mode path.

\paragraph{What it does not establish.}
Positive ForkAudit evidence remains one model/H20 family, 16-bit KV, one
sequential partial-tail factorial, and bounded same-adapter lifecycle paths---
not concurrent kernels, continuous batching, lower-precision KV, or binary
identity.  CoMem deployment, vLLM/SGLang, the 24-cell TP=1 HYPIC timing/quality
cohort, and the separate 16-cell HYPIC Store cohort are unpooled context.

\paragraph{Evidence limitations.}
Ranks are workloads, not replicates; most tensors ship as digests; replay
assumes honest capture; and neither oracle is end-to-end.  Appendix~\ref{app:expanded-limitations}
gives the full boundary.

\section{Reproducibility Statement}

Manifest-first CPU replays cover RR2, lifecycle/GDN, serving, scheduler, and
operator/policy transfers.  RR2 rechecks 536 artifacts, 96 factorial cells,
288 cross-$N$ comparisons, eight attention rows, and nine fault pairs.  HYPIC's
24 timing/quality cells bind a 4,404-entry terminal artifact ledger and
reaggregate byte-identically; independently, all 16 retained-state cells have
raw, pre-measurement, and terminal receipts and pass the hash-bound external
replay.  The terminal rerun closes source ledgers, 14 model rehashes,
and aggregate replay for that run only, not producer recapture; dispatch and
autotuning remain unbound.  Appendix~\ref{app:artifact} maps every package.

\section{Conclusion}

For one frozen Qwen3.5 sequential stack, \method{} makes lifecycle/storage
predicates receipt-complete only within trusted capture.  Selected oracles are
narrower corroboration, and nine mutations are positive controls rather than a
detection-rate estimate; per-call compiled dispatch and independent recapture
remain open.  Unpooled context establishes neither end-to-end correctness nor
concurrent serving, capacity, or a performance frontier.

\label{app:storage-schema}

Each tensor-view row has the exact fields
\texttt{storage\_id}, \texttt{shape}, \texttt{stride},
\texttt{storage\_offset}, \texttt{dtype}, \texttt{device},
\texttt{storage\_nbytes}, \texttt{tensor\_nbytes}, and
\texttt{content\_sha256}; absolute addresses are forbidden.  Within each
phase, the producer assigns \texttt{storage-0000}, \texttt{storage-0001},
and so on in first-observation order to backing storages.  Reusing an ID with
a different device or storage size is invalid.  Phase capture IDs are unique,
whereas request and persistent lifecycle-guard IDs must remain stable across
setup, first transition, and final generation.

Let element size be $e$, storage offset $o$, shape $s_i$, and stride $t_i$.
The independent replay initializes $m=M=o$ and, for every dimension, computes
\begin{equation}
  d_i=(s_i-1)t_i,\qquad
  m\mathrel{+}=\min(d_i,0),\qquad
  M\mathrel{+}=\max(d_i,0).
\end{equation}
The conservative half-open byte interval is
\begin{equation}
  I=[em,\,e(M+1)),
\end{equation}
which must be non-negative and contained in \texttt{storage\_nbytes}; also
\texttt{tensor\_nbytes}$=e\prod_i s_i$.  Two rows overlap iff their normalized
storage IDs match and $I_a^{\mathrm{start}}<I_b^{\mathrm{end}}$ and
$I_b^{\mathrm{start}}<I_a^{\mathrm{end}}$.  Exact aliasing additionally
requires equality of interval, geometry, dtype/device, storage and tensor
sizes, and content digest.  This bounding interval can conservatively flag an
exotic interleaved view, but it cannot miss a shared byte.

At setup, every recurrent-state coordinate must either exactly alias the
persistent state (borrowed-base arm) or be disjoint from it (materialized
arm).  After a request's first transition, its 60 mutable rows must be
disjoint from the base and every peer; incomplete borrowed requests must
remain exact aliases.  At the final phase all requests must be disjoint.
Independent binding-token receipts additionally require unchanged tokens for
incomplete requests and changed binding/storage tokens for completed requests.
The package applies this schema to all 96 timelines and 288 phase artifacts;
nine adversarial tests cover exact aliasing, partial overlap, adjacent
intervals, negative strides, conflicting ID reuse, pointer injection,
capture/guard reuse, and cross-coordinate request--base and request--peer
aliasing.

therefore not a primary replayable result of this paper package.

\section{Expanded Limitations and Claim Boundary}
\label{app:expanded-limitations}

The primary factorial covers one model, one H20 hardware family, one page
size, 16-bit KV, and $N\leq32$.  It has one 4,095-token partial-tail geometry;
the separate lifecycle cohort adds one aligned 4,096-token geometry and a
fixed cancel/scrub/reclaim sequence on the same adapter.  The formal scheduler
extension adds two page/prefix/tail geometries and one deterministic
request-step interleaving with cancellation and replacement, but not concurrent
CUDA kernels.  Requests are simultaneously resident but execute sequentially
on one CUDA stream.  The
separate eight-workload deployment context evaluates CoMem Q8/Q4 state and
single-request F1/timing, but the primary audit does not.  No cohort evaluates
continuous/ragged batching, eviction, arbitrary scheduler-level cancellation,
multi-document serving,
NVML memory, OOM capacity, or a broad downstream benchmark.  Full-copy
KV and materialized GDN bases are controlled ownership factors, not optimized
production baselines.  The GDN path is the Transformers Torch implementation,
not an optimized recurrent kernel.  The formal rerun hashes four compiled
runtime-cache artifacts, but the callable ledger does not bind each call to a
selected binary and exposes no explicit autotuning artifact.

The auxiliary serving panel uses one request stream per engine and compares
each cache-enabled framework only with its own disabled reference.  It does not
measure continuous batching, eviction, admission control, maximum concurrency,
or best-tuned performance.  CUDA graphs were disabled in both pinned runs; the
reported values describe that fixed configuration only.

The HYPIC timing/quality comparison uses the authors' exact tracked commit on
SGLang 0.5.14 in one fixed CUDA 12.9 / PyTorch 2.11 configuration, adapting
Qwen3.5 execution from the paper's TP=2 to TP=1 so every arm uses one H20-3e per
workload.  Cache-hit authority comes from OpenAI response usage.  Each of its 24
timing/quality cells has one formal measurement after a discarded,
prefix-disjoint warmup.  A separate receipt-instrumented run uses the same
model/slice and fixed TP=1 serving configuration to produce 8 Prefix Cache and
8 HYPIC retained-state cells; each completed cell binds raw output plus
pre-measurement and terminal ownership receipts, and all 16 pass an external
hash-bound replay.  The instrumentation adds target-entry byte-range receipts
and a lifecycle-idempotency overlay; Store therefore does not come from the
unmodified timing run.  Neither cohort establishes scheduler throughput, QPS,
capacity, the paper's TP=2 latency, or accuracy robustness beyond this
eight-item slice.

The same-checkpoint related-work transfer is likewise operator-bounded:
Hydragen uses one captured layer-3 shared-prefix attention family, and Palu
uses one layer with eight calibration rows and one held-out row.  Neither
executes all model layers, a fused Palu kernel, LongBench, or a jointly
optimized Hydragen/Palu-plus-CoMem serving path.

The page equations are deterministic identities, not learned laws; there is
one observation per rank--configuration cell and no stochastic replication.
Most runtime tensors are represented by hashes and equality receipts rather
than archived in full.  The attention and GDN oracle rows are the exception
and ship numerical sidecars, but cover only selected captured-input operator
boundaries rather than an end-to-end model.  The fully preregistered GDN run
starts after native q/k normalization and therefore does not validate that
upstream boundary.  Pointer-free normalized intervals
plus raw-byte hashes make the captured storage evidence replayable, not a proof
against a malicious producer before capture.  The nine mutants are targeted
positive controls; the M8/M9 debug adds one ordinary downstream catch and one
unmeasured runtime-detector cell, not incremental value.  The scheduler
extension's three frozen faults are expected-gate outcomes, not a detection
rate or evidence of fault-set completeness.  Broader systems claims would
additionally require a production serving scheduler with concurrent kernels,
optimized controls, alignment/length sweeps, and process-level accounting.
