The upstream project was used only as a style reference: minimalist
Matplotlib composition, Helvetica/Arial-like sans serif, blue/green/red/neutral
semantic colors, print-safe line/hatch redundancy, and vector-first export.
No upstream source code, demo layout, or visual asset was copied.  A clear
repository-level license file was not found during this inspection, which is
an additional reason to keep the implementation original.

## Reproducibility and QA

Two consecutive executions produced byte-identical architecture and teaser
PDF, SVG, and 600-dpi PNG hashes.  A fixed SVG hashsalt and suppressed
wall-clock metadata make the vector export deterministic.  The outputs are
regenerated by:

```bash
python3 scripts/generate_figures4papers_visuals.py
```

The selected assets must additionally be inspected at their final manuscript
size and in grayscale after every layout-changing merge.
