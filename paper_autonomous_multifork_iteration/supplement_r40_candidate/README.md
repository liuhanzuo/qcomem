# ForkAudit R40 anonymous supplement candidate

This directory is a metadata-redacted index for the R40 manuscript candidate.
It assigns neutral artifact aliases to evidence-registry entries and records
the exact limits of the locally available compiled-dispatch mirror.

This directory is **not yet a self-contained submission artifact**.  In
particular, it does not bundle the model view, every remote raw dispatch shard,
or all products named by the remote terminal ledger.  It therefore must not be
described as a complete local replay package.  The manuscript's quantitative
claims remain tied to the evidence IDs and hashes in the repository registry.

No absolute user paths, operator identities, scheduler job identifiers, or
trial identifiers are included here.  Internal handoff documents and remote
transport metadata are intentionally excluded.
