# Isolated designer input

This directory is the complete permitted input for a future isolated designer.
Repository source, private verifier implementation, tests, earlier cases,
execution outcomes, reviews, and author discussion are forbidden.

The designer returns exactly one sealed eight-row `fault-set.json` satisfying
`FAULT_SET_OUTPUT_SCHEMA.json`.  No case may name an expected gate or expected
outcome.  Cases cannot be revised, replaced, or withdrawn after their bytes are
frozen.

The resulting study is a constructed designer--executor-separated campaign,
not a natural-defect prevalence or population-recall study.
