# A14 / A31 / A32 evidence-grounded iteration

This workspace is an auditable revision run under the autonomous-paper-agent
workflow. Original polished inputs are frozen under each paper's `baseline/`;
all edits occur under `manuscript/`. Previous reviews are author-side context
only and are never placed in a blind reviewer snapshot.

The local inventory did not locate the experiment/result bundles referenced by
the manuscripts. Reported numbers are therefore preserved as source claims but
are marked `cannot_verify_locally` in the evidence registries until their frozen
artifacts are supplied. No missing experiment is treated as reproduced.

Blind reviewers receive only a frozen PDF, sanitized rubric and instructions,
schemas, and reviewer-facing evidence summaries. Internal score targets are
intentionally excluded from their context.
